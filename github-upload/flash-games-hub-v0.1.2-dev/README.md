# Publication du Hub v0.1.2-dev

Le CIA de cette version est `FlashGamesHub.cia`. Le manifeste publié à la
racine et dans `data/hub.json` annonce cette version et contient l'URL ainsi
que l'empreinte SHA-256 du paquet.

Après publication, la console peut récupérer `hub.json` et proposer la mise à
jour depuis la page Mises à jour.
