# Phases 2–9 — Prototype status

This is an independent, simplified remake prototype. It is not the original
game and is not affiliated with its publisher. The game rules and rendering
code are separate; selected SWF media was locally extracted for this remake
with the user's authorization.

## Phase 2 — Architecture and first milestone

- C++17 game logic is kept in `source/game.cpp` and `include/game.hpp`, without
  libctru or Citro2D dependencies.
- `source/main_3ds.cpp` renders the main scene on the top screen and touch
  controls on the bottom screen. `source/main_host.cpp` provides a terminal
  prototype using the same game model.
- The first milestone is now a simplified order route through take order,
  cooking, sandwich assembly, fries, service, result, and session progress.
- The fixed prototype ticket requests wholegrain bread, cheddar, medium cook,
  and regular fries.

## Phase 3 — Assets

- Four selected 128x80 ingredient sprites are packed into a Citro2D texture
  atlas. Only the needed still frames are included.
- Two audio files are signed 16-bit mono PCM WAV: the button sound
  (11,025 Hz) and order-screen music (22,050 Hz).
- The atlas is loaded only while the assembly station is active. The WAV files
  are copied into RomFS; the button sound plays when an order is served. The
  background music is packaged but not yet played.
- See [`asset-inventory.csv`](asset-inventory.csv) for paths, formats, and
  measured sizes. The local source extraction contains 8,258 files totaling
  92,512,472 bytes; that full extraction is not needed to build the project.

## Phase 4 — Shared game engine

- Implemented menu, station, pause, result, and session-progress states.
- Touch input and A/B/START buttons operate the route; the game model owns
  station selection, validation, transitions, and scoring.
- The current prototype uses static ingredient art; no animation playback is
  implemented. The serve sound uses NDSP and reports unavailable audio in the
  menu if the DSP or WAV asset cannot be initialized.

## Phase 5 — Stations

- A complete simplified route is playable, with validation at the cooking,
  assembly, and fries stations and a result screen after service.
- The mechanics are intentionally limited to the four ticket choices above;
  they do not claim feature parity with the original game.
- `tests/game_test.cpp` covers the route, station choices, incomplete input,
  cancellation, pause/resume, and scoring.

## Phase 6 — Progression and save

- Completed order count and cumulative score are saved to
  `sdmc:/3ds/CheeseShop3DS/progress.dat` after each served order.
- The save uses a versioned fixed-size format with a checksum; missing data
  starts a fresh session, while unreadable/corrupt data is reported on the menu
  and the game starts with fresh progress.
- In-progress station state is not saved; this prototype has no days or
  unlocks to persist yet.

## Remaining work

- **Phase 7:** test in an emulator and on Old/New 3DS hardware; measure memory,
  performance, and package size. No emulator or console test is recorded yet.
- **Phase 8:** create and validate a CIA, banner assets, RSF, and a unique
  homebrew Title ID. Only the `.3dsx` and SMDH are currently built.
- **Phase 9:** add a Hub catalogue entry only after a validated package,
  download URL, and SHA-256 are available.

The current devkitPro build measures 807,380 bytes for the `.3dsx`; the ELF
reports 167,908 bytes text, 7,560 bytes data, and 28,640 bytes BSS. These are
static build figures, not runtime memory or frame-rate measurements.

## Build and verification

- `.\build.ps1 3ds` builds `build/cheeseria.3dsx`, its SMDH, texture atlas, and
  RomFS WAV files with devkitPro.
- `.\build.ps1 host` and `.\build.ps1 test` require a native C++17 compiler.
- The 3DS build and test-source syntax check pass. Runtime host tests and
  emulator/device tests remain unverified because no native compiler or
  compatible emulator/device is available in the current environment.

def png_size(p):
    try:
        with open(p, "rb") as f:
            b = f.read(24)
        if b[1:4] == b"PNG":
            return struct.unpack(">II", b[16:24])
    except OSError:
        pass
    return None


def wav_info(p):
    try:
        with open(p, "rb") as f:
            b = f.read(44)
        if b[:4] == b"RIFF" and b[8:12] == b"WAVE":
            ch, rate = struct.unpack("<HI", b[22:28])
            bits = struct.unpack("<H", b[34:36])[0]
            return f"ch={ch} rate={rate} bits={bits}"
    except OSError:
        pass
    return ""


rows = []
for dp, dn, fn in os.walk(root):
    dn[:] = [d for d in dn if d not in SKIP]
    for f in fn:

#!/usr/bin/env python3
"""prepare_assets.py — prépare TOUS les assets exportés du SWF pour la 3DS.

  1. Images  : assets/source/images/*.png  -> réduites (--scale) -> atlas tex3ds
               (assets/atlases/atlas_NN.t3s + assets/atlases/img/img_<id>.png), max 1024x1024 par atlas
  2. Sons    : assets/source/sounds/*.wav  -> PCM 16 bits mono <= 22050 Hz -> romfs/audio/<nom>.wav
  3. Manifest: romfs/gfx/manifest.tsv (planche<TAB>index<TAB>nom) pour TOUS les .t3s de assets/

Usage (depuis la racine du projet) :
    pip install pillow
    python tools/prepare_assets.py                 # images à 50 % (écran 320x240), sons convertis
    python tools/prepare_assets.py --scale 0.625   # fonds 640x480 -> 400x300
    python tools/prepare_assets.py --skip-sounds
Puis :  .\\build.ps1 assets   (ou  .\\build.ps1 cia)
"""
import argparse
import array
import os
import re
import shutil
import sys
import wave

try:
    from PIL import Image
except ImportError:
    sys.exit("Pillow est requis :  pip install pillow")

ATLAS_SIZE = 1024
FILL_RATIO = 0.62      # part de la surface d'un atlas réellement remplie (marge pour le packing de tex3ds)
MAX_RATE = 22050


def leading_int(name):
    m = re.match(r"(\d+)", name)
    return int(m.group(1)) if m else 10 ** 9


# ── images ────────────────────────────────────────────────────────────────────
def prepare_images(src, out, scale, fmt):
    pngs = sorted((f for f in os.listdir(src) if f.lower().endswith(".png")),
                  key=lambda f: (leading_int(f), f))
    imgdir = os.path.join(out, "img")
    if os.path.isdir(out):
        for f in os.listdir(out):                      # régénération propre
            p = os.path.join(out, f)
            if f.startswith("atlas_") and f.endswith(".t3s"):
                os.remove(p)
    if os.path.isdir(imgdir):
        shutil.rmtree(imgdir)
    os.makedirs(imgdir, exist_ok=True)

    groups, cur, cur_area = [], [], 0
    cap = ATLAS_SIZE * ATLAS_SIZE * FILL_RATIO
    skipped = 0
    for f in pngs:
        try:
            im = Image.open(os.path.join(src, f)).convert("RGBA")
        except Exception as e:                          # fichier illisible
            print(f"  ! {f}: {e}")
            skipped += 1
            continue
        w = max(1, round(im.width * scale))
        h = max(1, round(im.height * scale))
        k = min(1.0, (ATLAS_SIZE - 2) / w, (ATLAS_SIZE - 2) / h)   # jamais plus grand qu'un atlas
        if k < 1.0:
            w, h = max(1, int(w * k)), max(1, int(h * k))
        if (w, h) != im.size:
            im = im.resize((w, h), Image.LANCZOS)
        stem = os.path.splitext(f)[0]
        name = "img_" + re.sub(r"[^0-9A-Za-z_]+", "_", stem)
        im.save(os.path.join(imgdir, name + ".png"))
        area = (w + 2) * (h + 2)
        if cur and cur_area + area > cap:
            groups.append(cur)
            cur, cur_area = [], 0
        cur.append(name)
        cur_area += area
    if cur:
        groups.append(cur)

    for i, g in enumerate(groups, 1):
        with open(os.path.join(out, f"atlas_{i:02d}.t3s"), "w", encoding="utf-8", newline="\n") as fh:
            fh.write(f"--atlas -f {fmt} -z auto\n")
            for name in g:
                fh.write(f"img/{name}.png\n")
    print(f"images : {len(pngs) - skipped} PNG -> {len(groups)} atlas (échelle {scale}, format {fmt})")
    return len(groups)


# ── sons ──────────────────────────────────────────────────────────────────────
def convert_wav(src_path, dst_path):
    with wave.open(src_path, "rb") as w:
        ch, sw, rate, n = w.getnchannels(), w.getsampwidth(), w.getframerate(), w.getnframes()
        raw = w.readframes(n)
    if sw == 1:                                         # 8 bits non signé
        samples = array.array("h", ((b - 128) << 8 for b in raw))
    elif sw == 2:
        samples = array.array("h")
        samples.frombytes(raw)
        if sys.byteorder == "big":
            samples.byteswap()
    else:
        raise ValueError(f"{sw * 8} bits non géré")
    if ch > 1:                                          # mixage mono
        samples = array.array("h", (sum(samples[i:i + ch]) // ch for i in range(0, len(samples) - ch + 1, ch)))
    if rate > MAX_RATE and len(samples) > 1:            # ré-échantillonnage linéaire
        ratio = rate / MAX_RATE
        m = int(len(samples) / ratio)
        res = array.array("h")
        for i in range(m):
            pos = i * ratio
            j = int(pos)
            frac = pos - j
            a = samples[j]
            b = samples[j + 1] if j + 1 < len(samples) else a
            res.append(int(a + (b - a) * frac))
        samples, rate = res, MAX_RATE
    os.makedirs(os.path.dirname(dst_path), exist_ok=True)
    with wave.open(dst_path, "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(rate)
        w.writeframes(samples.tobytes() if sys.byteorder == "little" else
                      (lambda a: (a.byteswap(), a.tobytes())[1])(array.array("h", samples)))
    return rate, len(samples) * 2


def clean_sound_name(fn):
    base = fn
    while base.lower().endswith(".wav"):
        base = base[:-4]
    base = re.sub(r"^-?\d+_", "", base)                  # "46_buildscreen_music" -> "buildscreen_music"
    return re.sub(r"[^0-9A-Za-z_]+", "_", base).strip("_").lower() or "snd"


def prepare_sounds(src, dst, overwrite):
    done, skipped, used = 0, 0, set()
    for fn in sorted(os.listdir(src), key=lambda f: (leading_int(f.lstrip("-")), f)):
        if not fn.lower().endswith(".wav"):
            continue
        name = clean_sound_name(fn)
        if name in used:                                 # doublon : on suffixe l'id d'origine
            name = f"{name}_{leading_int(fn.lstrip('-'))}"
        used.add(name)
        target = os.path.join(dst, name + ".wav")
        if os.path.exists(target) and not overwrite:
            skipped += 1
            continue
        try:
            rate, size = convert_wav(os.path.join(src, fn), target)
            if size > 2 * 1024 * 1024:
                print(f"  ! {name}.wav fait {size // 1024} Ko (> 2 Mo : refusé par audio_3ds.cpp)")
            done += 1
        except Exception as e:
            print(f"  ! {fn}: {e}")
    print(f"sons   : {done} convertis, {skipped} déjà présents (--overwrite pour remplacer) -> {dst}")


# ── manifest ──────────────────────────────────────────────────────────────────
def parse_t3s(path):
    names = []
    with open(path, encoding="utf-8-sig") as f:
        for raw in f:
            line = raw.strip()
            if not line or line.startswith("#") or line.startswith("-"):
                continue
            names.append(os.path.splitext(os.path.basename(line.replace("\\", "/")))[0])
    return names


def write_manifest(assets_root, out_path):
    t3s = []
    for root, _d, files in os.walk(assets_root):
        if os.path.sep + "source" in root + os.path.sep and os.path.relpath(root, assets_root).startswith("source"):
            continue
        t3s += [os.path.join(root, f) for f in files if f.lower().endswith(".t3s")]
    t3s.sort()
    os.makedirs(os.path.dirname(os.path.abspath(out_path)), exist_ok=True)
    total = 0
    with open(out_path, "w", encoding="utf-8", newline="\n") as out:
        out.write("# planche\tindex\tnom\n")
        for p in t3s:
            sheet = os.path.splitext(os.path.basename(p))[0]
            for i, name in enumerate(parse_t3s(p)):
                out.write(f"{sheet}\t{i}\t{name}\n")
                total += 1
    print(f"manifest : {len(t3s)} planches, {total} sprites -> {out_path}")


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--root", default=".", help="racine du projet")
    ap.add_argument("--scale", type=float, default=0.5, help="échelle des images (défaut 0.5)")
    ap.add_argument("--format", default="rgba8888", help="format tex3ds (rgba8888, rgba4444, rgba5551...)")
    ap.add_argument("--overwrite", action="store_true", help="remplacer les WAV déjà présents dans romfs/audio")
    ap.add_argument("--skip-images", action="store_true")
    ap.add_argument("--skip-sounds", action="store_true")
    a = ap.parse_args()
    r = os.path.abspath(a.root)

    if not a.skip_images:
        src = os.path.join(r, "assets", "source", "images")
        if os.path.isdir(src):
            prepare_images(src, os.path.join(r, "assets", "atlases"), a.scale, a.format)
        else:
            print("! assets/source/images introuvable")
    if not a.skip_sounds:
        src = os.path.join(r, "assets", "source", "sounds")
        if os.path.isdir(src):
            prepare_sounds(src, os.path.join(r, "romfs", "audio"), a.overwrite)
        else:
            print("! assets/source/sounds introuvable")
    write_manifest(os.path.join(r, "assets"), os.path.join(r, "romfs", "gfx", "manifest.tsv"))


if __name__ == "__main__":
    main()

def gen_banner_wav():
    """Génère banner.wav : 1 s de silence 16 bits stéréo 44100 Hz."""
    path = META / "banner.wav"
    n_samples = 44100
    with wave.open(str(path), 'w') as wf:
        wf.setnchannels(2)
        wf.setsampwidth(2)
        wf.setframerate(44100)
        # Jingle court (ding simple)
        data = array.array('h')
        for i in range(n_samples):
            t = i / 44100
            if t < 0.3:
                v = int(8000 * math.sin(2 * math.pi * 880 * t) * math.exp(-10 * t))
            else:
                v = 0
            data.append(v)
            data.append(v)
        wf.writeframes(data.tobytes())
    print(f"[OK] {path}  ({path.stat().st_size} octets)")

def _write_bmp(path, w, h, color):
    """Écrit un BMP couleur unie (sans Pillow)."""
    r, g, b = color
    row_size = ((w * 3 + 3) & ~3)
    pixel_data = bytes([b, g, r]) * w
    pixel_data += bytes(row_size - w * 3)
    pixel_data = pixel_data * h
    file_size = 54 + len(pixel_data)
    header = struct.pack('<2sIHHI', b'BM', file_size, 0, 0, 54)
    info   = struct.pack('<IiiHHIIiiII', 40, w, h, 1, 24, 0, len(pixel_data), 2835, 2835, 0, 0)
    with open(path, 'wb') as f:
        f.write(header + info + pixel_data)

param([string]$Root = (Get-Location).Path, [string]$Out = "inventory")
$ErrorActionPreference = "SilentlyContinue"
$Root = (Resolve-Path $Root).Path
$OutDir = Join-Path $Root $Out
New-Item -ItemType Directory -Force -Path $OutDir | Out-Null

$sb = New-Object System.Text.StringBuilder
function W([string]$s) { [void]$sb.AppendLine($s) }
function Rel([string]$p) { $p.Substring($Root.Length).TrimStart('\','/') }

$skip = '\\(\.git|node_modules|inventory)(\\|$)'
$files = @(Get-ChildItem -LiteralPath $Root -Recurse -File -Force | Where-Object { $_.FullName -notmatch $skip })

function Get-PngSize([string]$path) {
    try {
        $fs = [System.IO.File]::OpenRead($path); $b = New-Object byte[] 24
        $n = $fs.Read($b, 0, 24); $fs.Close()
        if ($n -ge 24 -and $b[1] -eq 0x50 -and $b[2] -eq 0x4E -and $b[3] -eq 0x47) {
            $w = ([int]$b[16] -shl 24) -bor ([int]$b[17] -shl 16) -bor ([int]$b[18] -shl 8) -bor [int]$b[19]
            $h = ([int]$b[20] -shl 24) -bor ([int]$b[21] -shl 16) -bor ([int]$b[22] -shl 8) -bor [int]$b[23]
            return @($w, $h)
        }
    } catch {}
    return $null
}
function Get-WavInfo([string]$path) {
    try {
        $fs = [System.IO.File]::OpenRead($path); $b = New-Object byte[] 44
        $n = $fs.Read($b, 0, 44); $fs.Close()
        if ($n -ge 44 -and $b[0] -eq 0x52 -and $b[8] -eq 0x57) {
            return "ch=$([BitConverter]::ToUInt16($b,22)) rate=$([BitConverter]::ToUInt32($b,24)) bits=$([BitConverter]::ToUInt16($b,34))"
        }
    } catch {}
    return ""
}

# ── CSV de tous les fichiers (taille, dimensions PNG, infos WAV) ──
$rows = foreach ($f in $files) {
    $ext = $f.Extension.ToLower(); $w = ""; $h = ""; $extra = ""
    if ($ext -eq ".png") { $s = Get-PngSize $f.FullName; if ($s) { $w = $s[0]; $h = $s[1] } }

#!/usr/bin/env python3
"""Inventaire complet du projet (équivalent de inventory.ps1, sans PowerShell).
Usage (depuis la racine du projet) :  python inventory.py
Produit : inventory/report.txt, inventory/files.csv et inventory.zip
"""
import csv, os, re, struct, sys, zipfile
from collections import Counter, defaultdict

root = os.path.abspath(sys.argv[1] if len(sys.argv) > 1 else ".")
out = os.path.join(root, "inventory")
os.makedirs(out, exist_ok=True)
SKIP = {".git", "node_modules", "inventory"}
MEDIA = {".png", ".wav", ".mp3", ".ogg", ".t3x", ".svg", ".jpg", ".gif"}
HIDE = MEDIA | {".o", ".d"}
TEXT_RX = re.compile(r"(^|/)(Makefile|\.gitignore|build\.ps1)$|\.(rsf|t3s|tsv|md|json|py|ps1|txt|cfg|yml|yaml|toml)$")


def png_size(p):
    try:
        with open(p, "rb") as f:
            b = f.read(24)
        if b[1:4] == b"PNG":
            return struct.unpack(">II", b[16:24])
    except OSError:
        pass
    return None


def wav_info(p):
    try:
        with open(p, "rb") as f:
            b = f.read(44)
        if b[:4] == b"RIFF" and b[8:12] == b"WAVE":
            ch, rate = struct.unpack("<HI", b[22:28])
            bits = struct.unpack("<H", b[34:36])[0]
            return f"ch={ch} rate={rate} bits={bits}"
    except OSError:
        pass
    return ""


rows = []
for dp, dn, fn in os.walk(root):
    dn[:] = [d for d in dn if d not in SKIP]
    for f in fn:
        full = os.path.join(dp, f)
        rel = os.path.relpath(full, root).replace("\\", "/")
        ext = os.path.splitext(f)[1].lower()
        w = h = ""
        extra = ""
        if ext == ".png":
            s = png_size(full)
            if s:
                w, h = s
        elif ext == ".wav":
            extra = wav_info(full)
        rows.append(dict(path=rel, size=os.path.getsize(full), ext=ext, width=w, height=h, extra=extra))
rows.sort(key=lambda r: r["path"])

with open(os.path.join(out, "files.csv"), "w", newline="", encoding="utf-8") as fh:
    wr = csv.DictWriter(fh, fieldnames=["path", "size", "ext", "width", "height", "extra"])
    wr.writeheader()
    wr.writerows(rows)

R = []
W = R.append
total = sum(r["size"] for r in rows)
W("=== INVENTAIRE ===")
W(f"Racine : {root}")
W(f"Fichiers : {len(rows)}   Taille totale : {total/1048576:.1f} Mo\n")

W("=== DOSSIERS DE PREMIER NIVEAU ===")
top = defaultdict(lambda: [0, 0])
for r in rows:
    k = r["path"].split("/")[0] if "/" in r["path"] else "(racine)"
    top[k][0] += 1
    top[k][1] += r["size"]
for k, (n, sz) in sorted(top.items()):
    W(f"{k:<20} {n:7d} fichiers {sz/1048576:9.2f} Mo")
W("\n=== EXTENSIONS (global) ===")
for e, n in Counter(r["ext"] or "(aucune)" for r in rows).most_common():
    W(f"{e:<10} {n:7d}")

W("\n=== DOSSIERS (images / sons) : nombre, tailles PNG min-max, exemples ===")
bydir = defaultdict(list)
for r in rows:
    if r["ext"] in MEDIA:
        bydir[os.path.dirname(r["path"])].append(r)
for d, g in sorted(bydir.items(), key=lambda kv: -len(kv[1]))[:200]:
    pngs = [r for r in g if r["width"] != ""]
    dim = ""
    if pngs:
        ws = [r["width"] for r in pngs]; hs = [r["height"] for r in pngs]
        dim = f"  PNG w:{min(ws)}-{max(ws)} h:{min(hs)}-{max(hs)}"
    W(f"[{d}] {len(g)} fichiers{dim}")
    for r in g[:12]:
        s = "    " + os.path.basename(r["path"])
        if r["width"] != "":
            s += f" ({r['width']}x{r['height']})"
        if r["extra"]:
            s += f" [{r['extra']}]"
        W(s)

W("\n=== AUTRES FICHIERS (code, config, docs, outils, scripts AS3...) ===")
for r in [r for r in rows if r["ext"] not in HIDE][:1500]:
    W(f"{r['path']}  ({r['size']} o)")

W("\n=== CONTENU DES FICHIERS CLES ===")
for r in rows:
    if TEXT_RX.search(r["path"]) and r["size"] < 400000 and not re.match(r"(build|extracted)/", r["path"]):
        W(f"----- {r['path']} ({r['size']} o) -----")
        with open(os.path.join(root, r["path"]), encoding="utf-8", errors="replace") as fh:
            t = fh.read()
        W(t[:30000] + ("\n[... tronqué ...]" if len(t) > 30000 else ""))

W("\n=== SOURCES (lignes) ===")
for r in rows:
    if r["ext"] in (".cpp", ".hpp", ".h", ".c") and not re.match(r"(build|extracted)/", r["path"]):
        with open(os.path.join(root, r["path"]), encoding="utf-8", errors="replace") as fh:
            W(f"{sum(1 for _ in fh):6d}  {r['path']}")

with open(os.path.join(out, "report.txt"), "w", encoding="utf-8") as fh:
    fh.write("\n".join(R) + "\n")
zp = os.path.join(root, "inventory.zip")
with zipfile.ZipFile(zp, "w", zipfile.ZIP_DEFLATED) as z:
    for n in ("report.txt", "files.csv"):
        z.write(os.path.join(out, n), n)
print("OK ->", zp, "(envoie ce fichier)")
